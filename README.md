# React + TypeScript + Vite

This project is built with React, TypeScript, and Vite.

It includes ESLint configuration for both TypeScript and JavaScript/JSX files, along with React Hooks and React Refresh rules.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Run ESLint:

```bash
npm run lint
```
